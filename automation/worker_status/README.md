# Worker consensus status

A/B/C write their latest independent assessment here on the control branch.

Verdicts:
- `CONTINUE`: at least one worthwhile concrete improvement remains in the active Specialist slice.
- `BLOCKED`: progress is blocked by a concrete source/tool/contract problem that should be solved or researched.
- `PLATEAU`: after inspecting the current exact public HEAD and current roadmap, the worker sees no worthwhile Specialist improvement to make now without lowering quality or duplicating evidence.

Private promotion is allowed only when A, B, C and Supervisor all independently conclude PLATEAU for the same exact GitHub Actions PASS HEAD.
